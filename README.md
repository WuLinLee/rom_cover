# GBA ROM 封面库

为个人 GBA 游戏库整理的封面集合，目前包含 **25 款游戏**。原始比例封面与正方形版本分开保存，方便不同模拟器前端使用。

## 目录结构

| 目录 | 用途 | 图片处理 |
|---|---|---|
| [GBA/](GBA/) | 原始封面 | 保留原图比例，不裁切 |
| [GBA_Square/](GBA_Square/) | 方形封面 | 统一为 512 × 512 PNG；优先使用找到的正方形原版图，否则从原图裁取视觉主体 |
| [scripts/generate_square_covers.py](scripts/generate_square_covers.py) | 方形封面生成脚本 | 可重复运行 |
| [.github/workflows/generate-square-covers.yml](.github/workflows/generate-square-covers.yml) | 自动化流程 | 推送封面或脚本更新后生成并提交方形图 |

## 方形封面的选图规则

1. **优先使用真正接近 1:1 的原版封面。** 目前已找到并用于方形版本的原版方图包括《公主同盟》《塞尔达传说：缩小帽》《星之卡比：镜之大迷宫》和《约束之地：利维艾拉》。
2. **没有合适的原版方图时，才裁切现有原图。** 脚本会根据图像细节、色彩和中心位置挑选正方形区域，尽量把主体内容留在画面内，不会拉伸人物或添加假背景。
3. 原图始终保留在 GBA/ 目录中。方形裁切可能会去掉原图边缘的标题、标志或装饰；想看完整封面时，请使用原始版本。

> 自动裁切通过图像细节与中心位置估算视觉重点，并不是人工逐张识别人物。如果某张方图没有保留最理想的构图，可以继续调整该图的裁切位置，或直接使用原始比例版本。

## 来源与版权

原始封面主要来自公开的 [Libretro GBA Named Boxarts](https://github.com/libretro-thumbnails/Nintendo_-_Game_Boy_Advance/tree/master/Named_Boxarts) 图片库。方形版本中，少数游戏使用同一游戏的其他地区原版封面，以获得更自然的 1:1 构图；这些区域版本可能与本地汉化 ROM 的地区标记不同。对于其余没有合适方图的作品，方形版来自原图裁切。

游戏封面、美术与角色版权均属于各自权利人。本仓库只整理封面图片，不包含任何 ROM 或汉化补丁。

## 重新生成

推送 GBA/ 的封面或更新生成脚本后，GitHub Actions 会自动更新 GBA_Square/。也可以在本地运行以下命令：

    python -m pip install Pillow numpy
    python scripts/generate_square_covers.py

脚本不会覆盖或修改 GBA/ 中的原始封面。

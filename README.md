# GBA ROM 封面

这个仓库收集了当前 GBA 目录中 25 款游戏的盒绘封面，图片放在 `GBA/` 目录下。每张图片的文件名对应 ROM 原文件名（仅把扩展名从 `.gba` 改成 `.png`），方便查找和配对。

## 来源与说明

封面来自公开的 [libretro-thumbnails / Nintendo - Game Boy Advance](https://github.com/libretro-thumbnails/Nintendo_-_Game_Boy_Advance/tree/master/Named_Boxarts) 封面集。封面展示的是对应游戏的原版发行封面，并非专门为中文汉化版制作的封面；个别没有合适日版图的作品使用了美版封面。游戏封面版权属于各自权利人。

本仓库只保存封面图片，不包含 ROM 或汉化补丁。

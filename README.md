# GBA ROM 封面库

为个人 GBA 游戏库整理的封面集合。当前包含 **25 款游戏**，原始封面与 1:1 方形版本分开保存，方便按不同模拟器前端的展示比例使用。

## 文件夹说明

| 目录 | 内容 | 是否裁切 |
|---|---|---|
| [GBA/](GBA/) | 原始比例封面 | 否，保留原图 |
| [GBA_Square/](GBA_Square/) | 统一为 1:1 的方形封面，PNG、512 × 512 | 仅为非方形原图选择方形区域 |

## 方形版的处理原则

1. **原图已经是正方形时**，保留完整画面，只统一输出尺寸。
2. **原图不是正方形时**，从原图中选择靠近视觉中心、颜色与细节较丰富的区域进行正方形裁切，并尽量避免偏离画面中心。
3. 不拉伸人物、不添加假背景，也不修改 GBA/ 下的原图。裁切可能去掉原图边缘的文字、标志或装饰；如需完整封面，请使用原始比例版本。

> 自动裁切依据图像边缘、色彩与中心位置估算视觉重点，并不等于人工逐张确认人物位置。若个别方形图没有保留最理想的主体构图，建议使用原始比例封面。

## 封面来源与使用说明

现有原始封面主要整理自公开的 [Libretro GBA Named Boxarts](https://github.com/libretro-thumbnails/Nintendo_-_Game_Boy_Advance/tree/master/Named_Boxarts) 图片库。它们是游戏原版发行封面/封面图，不是专门制作的中文汉化版封面。不同地区或版本可用的图片可能不同；封面、美术与角色版权归各自权利人所有。本仓库不包含 ROM 或汉化补丁。

## 更新方形封面

仓库附带 scripts/generate_square_covers.py，并使用 GitHub Actions 自动生成 GBA_Square/。当 GBA/ 原图或生成脚本更新并推送到 main 后，工作流会重新生成方形图片并提交结果。

也可以在本地手动运行：

    python -m pip install Pillow numpy
    python scripts/generate_square_covers.py

脚本只读取 GBA/，将方形结果写入 GBA_Square/，不会覆盖原始封面。
